# Development

Qwaderton Linux is built around the idea that software should be free, humane, and simple. Contributions should follow these principles.

## Guidelines

- **Keep it simple.** Prefer straightforward solutions over unnecessary complexity.
- **Avoid bloat.** Keep dependencies, abstractions, and additional features to a functional minimum.
- **Be consistent.** Follow the existing project's structure and coding style.
- **Respect existing work.** Understand the code before changing it.
- **Document changes.** Keep documentation relevant and up to date.

## Contributions

Contributions are welcome. Before submitting changes:

1. Check existing [issues](https://github.com/purrlinux/qwaderton/issues) and discussions to avoid duplicate work.
2. Keep changes focused and reasonably small.
3. Test your changes before submitting them.
4. Provide a clear description of what was changed and why.

Submit your changes through [pull requests](https://github.com/purrlinux/qwaderton/pulls) with a descriptive title and a concise explanation, if needed.
